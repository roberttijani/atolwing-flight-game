**AtolWing: Archipelago Sortie** is an original offline 3D twin-turboprop STOL flight game built for desktop browsers with no build step and zero network requests. Pilot the Kestrel-28 across a volcanic island chain featuring two marked aerodromes (`WARA RWY 09/27` and `WAKB RWY 14/32`) with dynamic 4-box PAPI glide-slope lights, animated windsocks, chase and 3D virtual cockpit cameras with live EFIS/HSI/EICAS displays, Web Audio propulsion synthesis, and four distinct sortie missions.

## Run it

```sh
# Play locally in desktop Chrome at http://localhost:8080
node serve.ts

# Build deterministic competition output and dossier.json
MAKEFUN_OUTPUT_DIR=out node main.ts
```
